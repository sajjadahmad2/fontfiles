# Font Files

This repository currently contains one font asset:

- `calendar-note-tfb.ttf.ttf`

## Usage

The file is a TrueType font asset. A project can reference it with a CSS font-face declaration after the font's intended family name and usage have been confirmed:

```css
@font-face {
  font-family: "CalendarNote";
  src: url("./calendar-note-tfb.ttf.ttf") format("truetype");
  font-display: swap;
}
```
